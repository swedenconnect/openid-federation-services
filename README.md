# OpenID Federation Services

[![License](https://img.shields.io/badge/License-Apache%202.0-blue.svg)](https://opensource.org/licenses/Apache-2.0)

The OpenID Federation Services implement the APIs required to support [OpenID Federation 1.0](https://openid.net/specs/openid-federation-1_0.html) — Trust Anchor, Intermediate, Trust Mark Issuer, and Resolver. The service can run standalone with static configuration or in managed mode against a [registry](https://github.com/swedenconnect/openid-federation-registry) service to enable management using a web interface.

## Maven artifacts

Versions up to 1.0.1 are published to Maven Central. Later versions are published only to the GitHub Packages Maven registry of this repository, which needs a GitHub token to download from. See [Using the Artifacts from GitHub Packages](https://docs.swedenconnect.se/openid-federation-services/github-packages.html).
